Site permissions — full reference

What each tier can do. There are two tiers today (Technical, Food Team) — built so more tiers can be added later without changing this structure.

Technical
Everything Food Team can do, plus: approve/un-approve recipes, promote/demote other accounts, reset anyone's password, and remove accounts. Technical manages the roster on this page.
Food Team
Full read/write access to shared data — Ingredients, Recipes, Projects, Reports, Export Templates. Create, edit, save and duplicate your own recipes freely. Saved Comparisons are personal: only you ever see comparisons you saved. Cannot approve/un-approve a recipe, and cannot manage other accounts.

Import from Excel / CSV

Upload a spreadsheet containing ingredients and/or recipes. Map your columns to NutriCalc fields below.

Column Mapping

Map your spreadsheet columns to NutriCalc fields. Only "Ingredient Name" is required — unmapped nutritional fields default to 0. Map "Item UOM" to the column that has KG, L, EACH (or eaches, litre, etc.) so each ingredient gets the correct cost unit.

Recipe library mode: Recipe column = which recipe/product each row belongs to (e.g. BCP Chives Prepared). Ingredient column = the component/input (e.g. RM Chives). So a row with Recipe=BCP Chives Prepared, Ingredient=RM Chives creates the link: BCP Chives Prepared is made from RM Chives. Rows with blank Recipe add the item to the library only (no recipe link).
